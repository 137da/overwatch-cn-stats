# overwatch-cn-stats

守望先锋**国服**战绩查询，本地桌面版。用网易大神扫码登录后，查任意玩家的段位、统计和对局。
程序完全在你自己的电脑上运行，不经过任何第三方服务器。

> **声明**：本项目是个人学习用的非官方工具，与网易、暴雪无关，也未获其授权。
> 它只是用你自己的账号凭据，调用网易大神网页版公开使用的接口，查询公开的战绩数据。
> 请只用于个人查询，**不要批量采集**：接口有风控，滥用会导致账号被封禁，后果自负。
> 接口随时可能变化或失效，本项目不保证可用性。

> 难免有 bug 或考虑不周的地方。请自行判断后再用；按 GPLv3 的约定，本项目不提供任何担保。

## 功能

- **查人**：段位、竞技 / 快速统计、近期对局，点开任一局看完整记分板
- **找对局**：按日期范围、时段、英雄、地图、同局玩家的名字或英雄，定位某一场比赛
- **玩家库**：查过的人自动记下，可收藏常用玩家
- **举报提醒**：用主号读取自己最近在游戏里举报的玩家并自动查他，方便避开（只读，不会发起举报）
- **命令行**：输出 JSON，方便 AI 或脚本调用

## 开始之前（重要）

1. **扫码的网易账号必须已在网易大神里绑定战网（Battle.net）。** 这是接口的硬性要求，没绑定拿不到凭据。
   国服战网号是暴雪各游戏共用的，玩魔兽、炉石的账号也可以。
2. ⚠️ **查询号请用小号，不要用自己的大号。** 所有查询都挂在这个账号上：查得太频繁会先被限流（HTTP 429），
   继续查就会被封禁（HTTP 403）。封禁针对账号本身，换 token、换 IP 都没用，也无法自行解封。
   自己的大号最多用来当「主号」，只看本人的举报记录。

## 安装与运行

目前只支持 **Windows**（界面依赖系统自带的 WebView2）。开发时用的是 Python 3.14。

```bash
pip install httpx pywebview
python -m ow_desktop
```

第一次打开会显示二维码，用网易大神 App 扫码登录即可。
扫码的人不必是你本人：把二维码发给符合条件的朋友扫一次就行，之后不需要再麻烦对方。

## 命令行

```bash
python -m ow_desktop guide                          # 完整手册（不发请求）
python -m ow_desktop status                         # 登录状态与今日用量（不发请求）
python -m ow_desktop player 玩家#12345 --mode sport  # 段位、统计、近期对局
python -m ow_desktop find 玩家#12345 --date 2026-10-12 --with 同局玩家名
```

- 输出是一段 UTF-8 JSON，退出码 0 表示成功；3 需要重新扫码，4 封禁，5 限流，看到 3/4/5 请停下，不要重试。
- 命令行每天的请求数有上限（默认 3000），可在界面「设置 → 命令行（CLI）」里调整。
- PowerShell 里用管道读输出时中文会乱码，先执行一次 `[Console]::OutputEncoding = [Text.Encoding]::UTF8`。

## 注意事项

- **凭据只存在本机**：`state/` 里是登录凭据，`data/` 里是本地玩家库，都不要发给别人，也不要提交到 git。
- **请求是排队、限速发出的**，界面和命令行共用同一个队列。请不要改小间隔或加并发。
- 网易只保留最近几个赛季的数据，老赛季查不到是正常的。
